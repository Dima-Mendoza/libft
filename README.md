# Libft

**Libft** — собственная реализация части стандартной библиотеки C (`libc`) и набора дополнительных вспомогательных функций.

Проект выполнен в рамках учебной программы **42** и помогает лучше разобраться в работе со строками, памятью, указателями, вводом-выводом и базовыми структурами данных.

## Что реализовано

* функции для работы с символами;
* функции для работы со строками;
* функции для работы с памятью;
* преобразование строк и чисел;
* вывод в стандартный поток и файловые дескрипторы;
* вспомогательные функции для связных списков.

Примеры реализованных функций:

```text
ft_strlen
ft_memcpy
ft_memmove
ft_atoi
ft_itoa
ft_strjoin
ft_strsplit
ft_putchar
ft_putstr
```

## Сборка

```bash
make
```

После сборки будет создана статическая библиотека:

```text
libft.a
```

Также доступна сборка динамической библиотеки:

```bash
make so
```

Очистка файлов сборки:

```bash
make clean
make fclean
make re
```

## Использование

```c
#include "libft.h"
```

Пример компиляции:

```bash
gcc main.c -L. -lft -o program
```
